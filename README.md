## Sobre o Gerenciador de Tarefas

Um simples gerenciador de tarefas com filtros, datas de prazo e checklist. Utiliza o localStorage para armazenar os dados.

## Como Instalar
Instale as dependências, executando este comando no terminal, na pasta raiz do projeto:

```
npm install
```

Pronto! Agora é só executar o seguinte comando para rodar a aplicação:

```
npm start
```
